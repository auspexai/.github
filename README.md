# AuspexAI Community & Governance Files

This repository holds organization-wide governance, conduct, and contribution files for the [AuspexAI](https://github.com/auspexai) organization. Files here are inherited as defaults by every repository in the org.

## Documents

- **[`GOVERNANCE.md`](GOVERNANCE.md)** — project governance: roles (Volunteer / Platform Contributor / Researcher / Approver / Maintainer), decision rules, recruitment, conflict of interest, amendment process
- **[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)** — community conduct standards (Contributor Covenant 2.1) plus AuspexAI-specific reporting procedure and escalation pathway when a Maintainer is the subject of a complaint
- **[`CONTRIBUTING.md`](CONTRIBUTING.md)** — how to contribute: contribution paths, DCO sign-off mechanics, PR workflow, RFC requirement for substantial architectural changes
- **[`RESEARCH_ETHICS_POLICY.md`](RESEARCH_ETHICS_POLICY.md)** — top-level governance document for AI safety research conducted on the AuspexAI network: dual-use distinction, permitted and prohibited research, containment requirements, ethics review process
- **[`LICENSE`](LICENSE)** — AGPL-3.0 (this repository; per-repo licenses vary)
- **[`profile/README.md`](profile/README.md)** — the org profile page rendered at https://github.com/auspexai

## Forthcoming

## Note on GitHub's community-standards UI

GitHub's auto-detected community-health surface only recognizes specific filenames (`README.md`, `LICENSE`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`). `GOVERNANCE.md` and `RESEARCH_ETHICS_POLICY.md` are project-specific governance documents not on that auto-detected list — they are surfaced via the index above and from the [org profile](https://github.com/auspexai), not via the auto-detection UI. Both are nonetheless authoritative project governance, on equal footing with the auto-detected files.
