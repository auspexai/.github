# AuspexAI Community Health Files

This repository holds organization-wide files for the [AuspexAI](https://github.com/auspexai) organization on GitHub:

- `profile/README.md` — the org profile page shown at https://github.com/auspexai
- Community health files (`CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`) and shared issue/PR templates will be added here as the project formalizes them.

Files here are not consumed by any application or library — they are GitHub-special files that the platform reads to render org-level content and policies.

For project information, see the [AuspexAI organization page](https://github.com/auspexai).
